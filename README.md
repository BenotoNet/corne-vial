# Corne-Vial-Configuration

This Repository is for hosting my own version of my Vial-configuration for my corne-like keyboard (40 keys)

optimized for 3 keyboard layouts (to convert between them):

  - Colemak (native)
  - QWERTY (conversion to Colemak if host is on QWERTY)
  - QWERTZ (conversion to Colemak if host is on QWERTZ)
